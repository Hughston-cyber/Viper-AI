# Viper AI — Team Venom HPR

Team Venom's digital information hub: rider statistics, race records (Calder, Casey Fields, Sandown), member accounts, invitation-based registration, captain approval and a private team dashboard.

**Status:** public landing page and dashboard preview. The sign-in forms are a front-end mock; no backend is connected yet.

## Run locally
Open `index.html` in a browser.
